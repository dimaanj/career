SMN · локальный запуск

Платформа SMN на одной машине

15 сервисов SMN с реальными образами и версиями из того же Helm-чарта, что и dev. Без стенда и без деплоя.

User ProfileSupport PanelRecommendations Prof Events · Offline Events · AnketologKeycloak · API Gateway
Зачем

Проверить изменение целиком можно было только на стенде

Веб-приложение, его сервер, Keycloak и шлюз работают вместе только там.

Долгий цикл

Каждая проверка — сборка в Jenkins и деплой через Argo CD.

Общий dev

Чужие изменения мешают, а эксперимент может сломать стенд другим.

Вход — только там

Логин через Keycloak и коды OTP не проверить на своей машине.

Цель: поднять рабочий срез платформы локально — с теми же версиями, входом и маршрутами, что на стенде.

Как устроено

Запрос идёт тем же путём, что на стенде

Каждый блок — отдельный файл apps/*.yaml, запускается по имени: coresupport-panelrecommendations prof-events · offline-events · anketolog

Маршрута нет в OpenAPI сервиса → шлюз отвечает 404 локально так же, как на стенде.

Нужны Docker (Colima, от 8 ГБ памяти), helm, jq. Секреты — только в локальном .env.

Что пришлось решить

Шесть мест, где «просто docker compose» не работал

Вход как на стенде

Keycloak за nginx по HTTPS; CSP темы дополняется на лету; убран цикл редиректов.

Логин в обычном Chrome без пересборки образов.

Трафик через шлюз

Веб-приложения ходят в API через API Gateway, маршруты строятся из OpenAPI сервисов.

Ошибка маршрута видна локально, а не после деплоя.

Блок на приложение

Пять новых блоков рядом с core; шлюз ведёт только в запущенные.

Поднимаешь только нужное; новый сервис — один файл.

Keycloak из чартов

Клиенты Support Panel, Prof Events, Anketolog, роли и оператор — из чартов сервисов.

Настройки входа не расходятся с dev, адреса сред не импортируются.

Swagger для 9 API

Спецификации отдаются по HTTPS, «Try it out» идёт через шлюз с токеном.

API любого сервиса можно потрогать без стенда.

Демо с нуля

Сиды пользователей, вебинаров и рекомендаций; порядок старта без взаимных блокировок.

Полный сценарий показывается на пустой базе.

Попутно: сборка recommendations, закреплённая в чарте, не создаёт схему БД. Обход описан в README, нужно передать команде сервиса.
